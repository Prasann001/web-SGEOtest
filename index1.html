The Problem

Real power grids sometimes can't supply electricity to every sector at once. During shortages, some areas must be prioritized over others.

⚠️ Shortages Happen

Demand can exceed supply — especially with variable renewable sources like sun and wind.

🏥 Not All Loads Are Equal

A hospital losing power is a matter of life and death. A street light going dark is an inconvenience.

🧠 Someone Must Decide

SGEO automates this decision — the same priority-based load shedding real utility companies use during blackouts.

How It Works

Solar and wind inputs are combined into a single power-availability index. The Arduino compares it against thresholds and switches relays to power zones in strict priority order.

Components

The hardware behind SGEO — each part plays a specific role in sensing, deciding, and switching power to the right zones.

🧠

Arduino UNO

The brain of the system. Reads sensor data every 500ms, computes the power-availability index, and drives all four relays in strict priority order.

tap ↻

Pins: A0 solar · A1 wind · A2 LDR
D2–D7 LCD · D8–D11 relays

☀️

Solar Panel

Primary renewable energy source. Feeds charging current through a blocking diode and reports voltage to the Arduino via a sensor on A0.

tap ↻

Path: Solar+ → 1N5408 diode → TP4056 IN+
Also taps into voltage sensor VCC

🌬️

Wind Mill (DC Motor)

Represents wind energy input. Wind availability is simulated through a potentiometer wired to A1, scaled into the total power index.

tap ↻

Control: Relay K4 · Pin D11
Turns on when wind raw > 511

🔋

TP4056 Charging Module

Safely charges the 3× Li-ion battery pack from the solar input and regulates a clean 5V output rail for the whole circuit.

tap ↻

Output: OUT+ → Relay COM bus + 5V rail
Never connect USB while battery is in

🔌

Voltage Sensor

Measures solar panel output voltage and reports the scaled analog reading to the Arduino for the power-index calculation.

tap ↻

Signal: S → A0
Scaled 0–245 raw into 0–1023 range

🌙

LDR Module

Detects ambient light. Gates the street-light zone so it only switches on at night, even when power is abundant — no wasted daylight lighting.

tap ↻

Signal: DO → A2
HIGH = dark (configurable in code)

🔀

4-Channel Relay Module

Active-LOW relays that physically switch power to the hospital, school, street-light, and windmill zones based on the Arduino's decisions.

tap ↻

Pins: D8 hosp · D9 school
D10 street · D11 windmill

🖥️

16×2 LCD Display

Shows the live power total and current grid status — HIGH, MODERATE, LOW, or CRITICAL — updated in real time from the sketch.

tap ↻

Mode: 4-bit · RS/E on D2/D3
D4–D7 data lines

💡

LED Zones

Red, green, and amber LEDs stand in for the hospital, school, and street-light loads — lighting up exactly as each zone is powered or shed.

tap ↻

Count: 3 red · 6 green · 12 amber
220Ω resistor on each LED

⚡

1N5408 Diode

A blocking diode on the solar input line, preventing reverse current from flowing back from the battery into the solar panel.

tap ↻

Role: One-way current gate
Protects panel when it's dark

The Arduino Code

#include <LiquidCrystal.h>

LiquidCrystal lcd(2, 3, 4, 5, 6, 7); // RS, E, D4, D5, D6, D7

const int solarPin = A0;
const int windPin   = A1;
const int ldrPin    = A2;

const int hospitalRelay = 8;
const int schoolRelay   = 9;
const int streetRelay   = 10;
const int windmillRelay = 11;

const bool RELAY_ACTIVE_LOW = true;

// If your LDR module prints 1 when dark, keep this true.
// If it prints 1 when bright instead, change this to false.
const bool LDR_HIGH_MEANS_DARK = true;

const int solarMaxRaw = 245;

const int HIGH_THRESHOLD     = 1400;
const int MODERATE_THRESHOLD = 900;
const int LOW_THRESHOLD      = 400;

void relayWrite(int pin, bool turnOn) {
  if (RELAY_ACTIVE_LOW) {
    digitalWrite(pin, turnOn ? LOW : HIGH);
  } else {
    digitalWrite(pin, turnOn ? HIGH : LOW);
  }
}

bool isDark() {
  int reading = digitalRead(ldrPin);
  if (LDR_HIGH_MEANS_DARK) {
    return reading == HIGH;
  } else {
    return reading == LOW;
  }
}

void setup() {
  pinMode(hospitalRelay, OUTPUT);
  pinMode(schoolRelay, OUTPUT);
  pinMode(streetRelay, OUTPUT);
  pinMode(windmillRelay, OUTPUT);
  pinMode(ldrPin, INPUT);

  relayWrite(hospitalRelay, false);
  relayWrite(schoolRelay, false);
  relayWrite(streetRelay, false);
  relayWrite(windmillRelay, false);

  lcd.begin(16, 2);
  lcd.print("Smart Grid Init");

  Serial.begin(9600);
  delay(1000);
  lcd.clear();
}

void loop() {
  int solarRaw = analogRead(solarPin);
  int windRaw  = analogRead(windPin);
  bool dark    = isDark();

  int solarScaled = map(solarRaw, 0, solarMaxRaw, 0, 1023);
  solarScaled = constrain(solarScaled, 0, 1023);

  int total = solarScaled + windRaw;

  Serial.print("Solar raw: "); Serial.print(solarRaw);
  Serial.print(" | Solar scaled: "); Serial.print(solarScaled);
  Serial.print(" | Wind raw: "); Serial.print(windRaw);
  Serial.print(" | Total: "); Serial.print(total);
  Serial.print(" | Dark: "); Serial.println(dark ? "YES" : "NO");

  relayWrite(windmillRelay, windRaw > 511);

  lcd.setCursor(0, 0);
  lcd.print("Total:");
  lcd.print(total);
  lcd.print("     ");

  lcd.setCursor(0, 1);

  if (total >= HIGH_THRESHOLD) {
    relayWrite(hospitalRelay, true);
    relayWrite(schoolRelay, true);
    relayWrite(streetRelay, dark);
    lcd.print(dark ? "HIGH: all ON   " : "HIGH: street off");

  } else if (total >= MODERATE_THRESHOLD) {
    relayWrite(hospitalRelay, true);
    relayWrite(schoolRelay, true);
    relayWrite(streetRelay, false);
    lcd.print("MODERATE       ");

  } else if (total >= LOW_THRESHOLD) {
    relayWrite(hospitalRelay, true);
    relayWrite(schoolRelay, false);
    relayWrite(streetRelay, false);
    lcd.print("LOW: hosp only ");

  } else {
    relayWrite(hospitalRelay, true);
    relayWrite(schoolRelay, false);
    relayWrite(streetRelay, false);
    lcd.print("CRITICAL       ");
  }

  delay(500);
}
